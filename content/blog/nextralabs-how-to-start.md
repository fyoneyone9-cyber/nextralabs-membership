# NextraLabsの始め方完全ガイド

## NextraLabsとは

NextraLabsはChatGPT・Claude・Gemini・画像生成AI・動画生成AIなど30種類以上のAIツールが月額定額で使い放題のサービスです。

## 会員登録の手順

### ステップ1：公式サイトにアクセス
NextraLabsの公式サイト（nextralab.jp）にアクセスします。

### ステップ2：プランを選択
料金プランページから自分に合ったプランを選びます。

### ステップ3：アカウント作成
- メールアドレスを入力
- パスワードを設定
- 支払い情報を入力

### ステップ4：ダッシュボードにログイン
登録完了後、ダッシュボードからすぐにAIツールを使い始められます。

## 使えるAIツール一覧

- **テキスト生成**：ChatGPT / Claude / Gemini
- **画像生成**：Stable Diffusion / DALL-E 系
- **動画生成**：Kling / Hailuo 系
- **音声生成**：TTS・音楽生成
- **文書作成**：スライド・レポート自動生成
